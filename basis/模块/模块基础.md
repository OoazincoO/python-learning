## 介绍
Python模块(module):
==一个.py文件就是一个模块==，模块是Python程序的基本组织单位。在模块中可以定义[[字面量与变量|变量]]、[[函数基础|函数]]、[[类与对象|类]]，以及可执行的代码。
## 模块导入方式 #导入
- 在使用模块中提供的功能之前，==必须得先导入，再使用==。
- 导入模块的具体语法如下:

| 导入形式                            | 代码样例                                 | 调用方式    | 调用方式                      |
| ------------------------------- | ------------------------------------ | ------- | ------------------------- |
| `import 模块名`                    | `import random, os`                  | 模块名.功能名 | `random.randint(10, 100)` |
| `import 模块名 as 别名`              | `import random as rd`                | 别名.功能名  | `rd.randint(10, 100)`     |
| `from 模块名 import 功能名`           | `from random import randint,choice`  | 功能名     | `randint(10, 100)`        |
| `from 模块名 import 功能名 as 别名`     | `from random import randint as rint` | 别名      | `rint(10, 100)`           |
| `from 模块名 import \*(\*号表所有功能名)` | `from random import *`               | 功能名     | `randint(10, 100)`        |

> [!warning] `from 模块名 import *` 要慎用
> 一次性导入所有功能名，容易跟当前文件里的名字冲突，出了问题也不知道某个功能来自哪个模块。平时优先用 `import 模块名` 或明确导入具体功能。

> [!tip] 起别名的时机
> 模块名/功能名太长、或跟现有名字冲突时用 `as` 别名（如 `import random as rd`），写起来短，语义不变。

### 同名冲突 #命名冲突
两个模块里有同名功能时，==后导入的会覆盖先导入的==：
```python
from time import sleep
from mymod import sleep  # 后导入

sleep()  # 实际调用的是 mymod 里的 sleep
```

所以功能重名时，用 `import 模块名` 的方式导入更安全，调用时带模块名就不会混。

## 自定义模块 #自定义模块

- 当开发一些复杂的项目，为了让项目结构更清晰，更便于项目的维护 管理及代码的复用，可能会把一个项目拆分为若干个模块。
注意:每一个python文件都可以作为一个模块，==模块的名字就是文件的名字==(建议使用python标识符定义，规范命名)

> [!info] 模块的来源不止自定义
> 除了自己写的模块，Python 还自带大量标准库模块（random、os、json 等），常见清单见 [[python中自带的模块]]。

### 自定义模块示例

自己写一个 `.py` 文件，就是自定义模块。

`my_tools.py`：

```python
def add(x, y):
    return x + y

PI = 3.14
```
在另一个文件里导入使用（==两个文件要放在同一目录下==）：

```python
import my_tools

print(my_tools.add(1, 2))  # 3
print(my_tools.PI)         # 3.14
```
注意：
- 模块名要符合标识符命名规则，不要用中文、==不要和 [[python中自带的模块|内置模块]] 重名==（比如不要把自己的文件起名叫 `random.py`，会把内置的顶掉）。
- 导入模块时，==该模块里的顶层代码会被执行一遍==（见下文 `__name__` 与 `__main__` 一节）。
## `__name__` 与 `__main__` #主程序入口 

每个模块里都有一个内置变量 `__name__`：

- ==直接运行这个文件时，`__name__` 的值是 `"__main__"`==。
- ==被别的文件导入时，`__name__` 的值是模块名==。

所以测试代码要这样写，别人才导入你的模块时，测试代码不会被误执行：

```python
def add(x, y):
    return x + y

if __name__ == "__main__": # 只有直接运行本文件时才会执行这里
    print(add(1, 2))
```

> [!tip] 测试代码模板
> 调试/测试代码一律放进 `if __name__ == "__main__":` 里：直接运行照常执行，被别人 import 时不会误跑。

## `__all__` 变量

在模块里定义 `__all__`，可以控制 `from 模块 import *` 时到底导入哪些功能：
`# my_tools.py`
```python
__all__ = ["add"]  # 用 * 导入时只导入 add

def add(x, y):
    return x + y

def sub(x, y):
    return x - y
```
> [!warning] `__all__` 的作用范围
> ==`__all__` 只对 `import *` 有影响==；用 `import my_tools` 或 `from my_tools import sub` 照样能导入 `sub`。

## 包（Package） #包

包就是一个装了多个模块的文件夹，用来管理一大堆相关模块。

结构示例：

```
my_package/
    __init__.py     # 有了它，这个文件夹才被认作包（新版本 Python 可省略，但写上更规范）
    mod_a.py
    mod_b.py
```

导入方式：

|导入形式|代码样例|调用方式|调用样例|
|---|---|---|---|
|`import 包名.模块名`|`import utils.my_fun`|包名.模块名.功能名|`utils.my_fun.log_separator1()`|
|`from 包名 import 模块名`|`from utils import my_fun`|模块名.功能名|`my_fun.log_separator1()`|
|`from 包名 import *`|`from utils import *`|模块名.功能名|`my_fun.log_separator1()`|
|`from 包名.模块名 import 功能名`|`from utils.my_fun import log_separator1`|功能名|`log_separator1()`|
|`from 包名.模块名 import *`|`from utils.my_fun import *`|功能名|`log_separator1()`|

> [!warning] 两种 `import *` 拿到手的东西不一样
> `from 包名 import *` 拿到的是**模块名**，调用要写 `模块名.功能名`；`from 包名.模块名 import *` 拿到的才是**功能名**，直接调用。对照表格最后两行记。

```python
import my_package.mod_a
my_package.mod_a.func()
```

```python
from my_package import mod_a
mod_a.func()
```

```python
from my_package.mod_a import func
func()
```
包的 `__init__.py` 里也可以写 `__all__`，==控制 `from 包 import *` 时导入哪些模块==。
