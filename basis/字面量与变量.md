## 字面量
1.整数(int)`print(100)
2.浮点数(float)`print(3.14)
3.布尔(bool):真或假---True False `print(True)` `print(False)`
	布尔类型本质也为整数类型(Ture为1,False为0)
`print(True-1)`
`print(False+1)`
4.字符串(str):描述文本的一种数据类型----"hello world"`print("hello world")
5.空值(nonetype):空或无值---none`print(none)

## 变量
**python为动态类型语言,一个变量可以存储不同类型的数据的(但是项目开发中,推荐变量只存储一种类型的数据)
*变量定义的时候必须赋值才可以使用
```python
num = 1123.2  
print(num)  
  
num = num + 1  
print(num)  
  
num = "OK"  
print(num)  
  
num = True  
print(num)  
num = False  
print(num)
```

## 案例
```python
base = 20.5 #基础播放量  
incr = 50 #每一个月的新增播放量  
print("未来第一个月的播放总量",base + incr)  
print("未来第二个月的播放总量",base + incr + incr)
```
## 案例:一次性可以定义多个变量
```python
base,incr = 20.5,50  
print("未来第一个月的播放总量",base + incr)  
print("未来第二个月的播放总量",base + incr + incr)
```
