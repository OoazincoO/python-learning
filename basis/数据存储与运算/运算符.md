**算数运算符的优先级**------>==`**` > `*  /  //  %` > `+  -`==  依次递减
`print("0.1 +10/4**2=\",0.1+10/4**2)`
### 案例:输入两个数x和y,计算x+y和x-y并输出结果
```python
x = float(input("请输入x的值:"))  
y = float(input("请输入y的值:"))  
  
#0.0999999999999998---->精度损失;计算机底层是基于二进制,而二进制无法精确的表示所有的小数,因此涉及浮点数的运算可能会损失精度  
  
print("x + y =", x + y)  
print("x - y =", x - y)
```

> [!warning] 浮点数精度损失
> ==计算机底层基于二进制，无法精确表示所有小数==，所以涉及浮点数的运算可能有误差（如 0.1+0.2 不精确等于 0.3）。需要精确计算的场景（钱）要特别小心。

## 赋值运算符 #赋值运算符
```python
num += 2  #为num = num + 2  
num -= 2  #为num = num - 2  
num *= 2  #为num = num * 2  
num /= 2  #为num = num / 2  
num //= 2  #为num = num // 2  
num %= 2  #为num = num % 2  
num **= 2  #为num = num ** 2
```

## 逻辑运算符
**and  or  not**
### 案例
**需求1:输入一个整数,判断这个数字是否在10-20之间**
```python
num = float(input("请输入一个整数:"))  
print(num>=10 and num<=20)

```
**需求2:输入一个整数,判断这个数字是否在10-20以外**
```python
num = float(input("请输入一个整数:"))  
print(num<10 or num>20)

```
***使用not判断这个数字是否在10-20以内***
```python
print(not (num<10 or num>20))
```
