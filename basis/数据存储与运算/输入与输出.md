获取键盘上输入的数据`input(..)
```python
name = input("请输入您的姓名:")  
age = input("请输入您的年龄:")  
print(f"欢迎您,{name}")  
print(f"您今年{age}岁")

```
==`print()`***语句自带换行效果***==
**若需输入再同一行则将语句改为**
`print(m,end=" ")`   *end表示的是每一次输出都以什么结束;默认是\n,表换行*
## 案例 : 银行卡ATM取款
```python
#总金额  
total = 10000  
  
#1.输入密码(暂不设定密码校验)  
password = input("请输入您的银行密码:")  
print(f"密码正确,{password}")  
  
#2.输入取款金额  
num = input("请输入您的取款金额:")  
  
#3.计算余额并输出---->str类型转为int类型---->int(...)  
print(f"取款后银行卡余额为:{total-int(num)}")  
  
  
#练习:实现计算机加法功能

```
