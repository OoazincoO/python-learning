t`ype()`type()获取指定字面量或变量的类型
```python
print("hello")  
print(type("hello"))#str  
  
print(type(10))# int  
print(type(3.14)) # float  
print(type(True)) # bool  
print(type(False)) # bool  
print(type(None))#NoneType  
  
num = -100  
print(type(num)) # int
```

其它类型转int类型  `int(...)  
其它类型转str类型  `str(...)  
其它类型转float类型  `float(...)  
其它类型转bool类型  `bool(...)
## 字符串
**定义字符串的三种方式
```python
s1 = "hello" #双引号定义  
s2 = 'world' #单引号定义  
s3 = """  
NIHAO  
    WOZAI""" #三引号定义(多行字符串)  
print(s1)  
print(s2)  
print(s3)  
  
print(type(s1),type(s2),type(s3))
```

**转义字符` \' \" \n \t`
```python
msg = 'It\'s very good'  
print(msg)  
msg2 = "It's very good"  
print(msg2)  
msg3 ="hello的意思是\"你好\""  
print(msg3)  
msg4 = 'hello的意思是"你好"'  
print(msg4)  
msg5 = "nihao\nwozai"  #回车  
print(msg5)  
msg6 = "大家好\t我在"  #缩进  
print(msg6)
```

### 案例

**str(int类型的数字)------>转为int类型的数字转为字符串

```python
name = "张三"  
age = 18  
pro = "计算机"  
hobby = "PYTHON"  
print("大家好,我是"+name + ",今年" + str(age) + "岁" + ",学习的专业是" + pro +  ",爱好是" + hobby)
```
## 字符串格式化
### 方式一:  %s 占位符
```python
s1 = "张三"  
print("大家好,我叫%s" % s1)  
s2 = "广东"  
print("大家好,我叫%s,我来自%s" % (s1,s2))  
  
  
name = "张三"  
age = 18  
pro = "计算机"  
hobby = "PYTHON"  
print("大家好,我是%s,今年%s岁,学习的专业是%s,爱好是%s" %(name,age,pro,hobby))
```
### 方式二(推荐方式):  f"...{变量名/表达式}..."
```python
name = "张三"  
age = 18  
pro = "计算机"  
hobby = "PYTHON"  
print(f"大家好,我是{name},今年{age}岁,学习的专业是{pro},爱好是{hobby}")
```
