## 介绍:
元组是**不可变**的序列,类似于[[列表(list)|列表]],但创建后不可修改.
### 特点:
- 可以存储不同类型的元素
- 元素可以重复,有序,不可以修改(支持索引访问,切片)
### 与列表的区别:
- 列表中的元素是可重复,有序,可以修改的
- 而元组定义完成后,是不可修改的
- 元组定义的时候用的是小括号()而列表为中括号\[]
### 定义:
```
#定义元组
元组名称 = (元素1,元素2,.....)
t1 = (5,7,8,2,3,4,6,121323,44,123)

#定义空元组
元组名称 = ()
元组名称 = tuple()
t2 = ()
t3 = tuple()
```

### 方法:
- count():统计某元素在元组中出现的次数
- index():查找某个元素在元组中的索引位置(第一次出现的位置)
## 元组操作

### 索引访问
与列表一致

```python
t1 = (23,42,314,123,5,1,2,3,42,51)

print(t1[0])  # 输出结果为23
print(t1[-1])  #输出结果为51
```
### 切片 #切片
与列表一致

```python
t1 = (23,42,314,123,5,1,2,3,51)

print(t1[0:5:1])

```
### 统计元素的个数
```python
print(t1.count(42)) # 输出的结果为2
```

### 获取元素的索引(第一个元素的位置)
```python
print(t1.index(314)) #输出结果为2
```

### 定义单元素元组
如果定义单元素的元组,须在元组后加个逗号","
```python
t2 = (100,)
```

### 组包(packing) #解包
将多个值合并到一个容器(元组,列表)中.
**也就是定义
```python
#定义元组,解包
t1 = (5,4,7,6)
t2 = 5,4,7,6
```
### 解包(unpacking)
将容器(元组,列表)解开成独立的元素,分别赋值给多个[[字面量与变量|变量]].
**在元组解包时,\*表示收集剩余的所有元素,允许我们处理不确定数量的元素(生成列表,与便于可以进行进一步的处理).
```python
#基础解包
a,b,c,d = t1

#(*)扩展解包
x,*y,z = t2  #x为5,y为[4,7],z为6
s,*o = t2  #s为5,o为[4,7,6]
*o,e = t2  #o为[5,4,7],e为6
```
