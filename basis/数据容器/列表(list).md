## 介绍
**列表是数据容器中的一类，是一次性可以存储多个数据(元素)的。**
### 定义
`列表名称 = [元素1,元素2,元素3......]`
`s = [23,345,11,5523,331,312]`
### 特点
+ ==可以存储不同类型的元素==
+ *==元素有序,可以重复,元素可以修改==*

列表内每个元素都会配备一个下标,即索引==(从0开始)==
对应的第一个元素为s\[0\] ,第二个元素为s\[1\]....

 *还有提供一种索引,为反向索引,从倒数第一个开始,第一个为-1,第二个为-2..........*
 对应的倒数第一个为s\[-1\],第二个为s\[-2\]......

#### 序列类型 #序列
容器中的元素按特定顺序排列的,且可通过索引访问的容器类型称之为**序列**.

## 列表操作

### 删除
`del s[6]`
> [!warning] 删除会"塌缩"
> ==删除列表中间的元素后,后续元素会顶替上来==（索引整体前移），后续按索引取值要留意。

### 遍历
```python
for item in s:
	print(item)
```
将从头将元素逐个打印

### 切片 #切片

#### 介绍
切片是指对操作的数据截取其中一部分的操作。列表、[[字符串(str)|字符串]]、[[元组(tuple)|元组]]都支持切片操作.

#### 语法
`序列数据[开始索引:结束索引:步长]`
+ **不包含**==结束索引==位置对应的元素（开始索引未指定*默认为0*;结束索引未指定*认为直到列表末尾*;步长未指定*默认为1*）
+ 索引采用正向索引和反向索引都可以
+ 步长是选取间隔,默认为1
#### 举例
`s = ["A","C","E","B","D","E","G"]`
`s[0:5:1]`切片后的结果为`["A","C","E","B","D"]`
`s[:5:]`切片后的结果为`["A","C","E","B","D"]`
`s[:5]`切片后的结果为`["A","C","E","B","D"]`
`s[0:5:2]`切片后的结果为`["A","E","D"]`
`s[0:-2:1]`切片后的结果为`["A","C","E","B","D","E"]`

> [!tip] 切片速记
> ==切片是"包头不包尾"==：`s[a:b]` 取得到 a、取不到 b。三种容器通用，语法一模一样。

### 常见方法

|     方法      |                 作用                 |               样例               |
| :---------: | :--------------------------------: | :----------------------------: |
| `append()`  |             在列表的尾部追加元素             |       `s.append(10086)`        |
| `insert()`  |           在指定索引之前，插入该元素            | `s.insert(0,92)`(在0号索引前添加元素92) |
| `remove()`  |           移除列表中第一个匹配到的值            |         `s.remove(75)`         |
|   `pop()`   |  删除列表中指定索引位置的元素(如果未指定索引，默认删最后一个)   |  `s.pop(2)`<br>/<br>`s.pop()`  |
|  `sort()`   | 对列表进行排序<br>*(列表元素的[[常见的数据类型|数据类型]]一致，才可以进行排序)* |           `s.sort()`           |
| `reverse()` |               反转列表元素               |         `s.reverse()`          |

> [!warning] sort() 的前提
> ==列表元素类型必须一致才能排序==，混着放数字和字符串会报错。

###  解包及组包 #解包
#### 介绍
将列表这一类容器解开成一个个独立的元素

#### 方法
`*num_list1` 使用\*号

#### 组包例子
```python
num_list1 = [22,23,554,31,26,41,67,21]
num_list2 = [33,12,54,23,45,27,31]
num_list = [*num_list1,*num_list2]
print(num_list)
```
打印结果为:[22,23,554,31,26,41,67,21,33,12,54,23,45,27,31]

### 推导式 #推导式
*语法格式1*:\[要输入的值 for i in 序列/列表]
*语法格式2:*\[要插入的值 for i in 序列/列表 if 条件]

> [!tip] 推导式
> ==一行顶四行==，把"建空列表→循环→append→判断"压成一行。格式 2 的 `if` 是过滤条件。


## 案例
### 一.
将用户输入的10个数字和平均值。存储到一个列表中，并将列表中的数字进行排序，输出其中的最小值、最大值.
```python
#1.定义列表
num_list = []

#2.将用户输入的10个数字存入列表
for i in range(10):
	num = int(input("请输入一个有效的数字:"))
	num_list.append(num)

print("数字列表:",num_list)

#3.排序
num_list.sort()
print("排序后的数字列表:",num_list)

#4.输出其中的最小值,最大值和平均值.
print("最小值是:",num_list[0],",最大值是:",num_list[-1])
print("平均值:",sum(num_list)/len(num_list))
```
**`sum()`为求和,`len()`获取列表长度**

### 二.
合并两个列表中的元素，并对合并的结果进行去重处理
(去除列表中的重复元素)

#### 方法一
```python
num_list1 = [22,23,554,31,26,41,67,21]
num_list2 = [33,12,54,23,45,27,31]

#1.合并列表
for num in num_list2:
	num_list1.append(num)
print("合并后的原始列表:",num_list1)

#2.去除重复记录
new_list = []

for num in num_list1:#判断new_list中是否存在num元素,如果不存在再添加
	if num not in new_list:
		new_list.append(num)

print("去除重复记录后的列表:",new_list)
```

#### 方法二
```python
num_list1 = [22,23,554,31,26,41,67,21]
num_list2 = [33,12,54,23,45,27,31]

#1.合并列表
num_list = [*num_list1,*num_list2]
print("合并后的原始列表:",num_list)

#2.去除重复记录
new_list = []

for num in num_list:#判断new_list中是否存在num元素,如果不存在再添加
	if num not in new_list:
		new_list.append(num)

print("去除重复记录后的列表:",new_list)
```

#### 方法三
```python
num_list1 = [22,23,554,31,26,41,67,21]
num_list2 = [33,12,54,23,45,27,31]

#1.合并列表
num_list = num_list1 + num_list2
print("合并后的原始列表:",num_list)

#2.去除重复记录
new_list = []

for num in num_list:#判断new_list中是否存在num元素,如果不存在再添加
	if num not in new_list:
		new_list.append(num)

print("去除重复记录后的列表:",new_list)
```

> [!info] 去重还有更优解
> 现在的去重是 O(n²)（每加一个都扫一遍新列表）。学完 [[集合(set)|集合]] 后可以用 set() 一行去重（但会丢顺序），学完 [[字典(dict)|字典]] 后还有保序去重的写法。

### 三.
 生成1-20的平方列表.
#### 方法一
```python
num_list = []
for i in range(1,21):
	num_list.append(i**2)

print(num_list)
```

#### 方法二:列表推导式
```python
num_list2 = [i**2 for i in range(1,21)]
print(num_list2)
```

### 四.
从一个数字列表中提取***所有偶数***,计算其平方,组成一个新的列表.
```python
num_list = [12,32,45,77,80,92,33,57,97,98,110,111,112]
new_list = [i**2 for i in num_list if i % 2 == 0]
print(new_list)
```
