- 魔法方法是指Python中提供的==以双下划线开头和结尾==的特殊方法，用于定义[[类与对象|类]]的特殊行为，比如:`__init__`。
- ==魔法方法不需要我们手动调用，Python会在合适的时机自动调用==。
常见魔法方法:

| 魔法方法       | 描述                                               |
| ---------- | ------------------------------------------------ |
| `__init__` | 初始化方法                                            |
| `__str__`  | 字符串表示的方法                                         |
| `__eq__`   | 比较两个对象是否相等(equal)                                |
| `__lt__`   | 支持比较两个对象的大小(小于(**l**ess **t**han))               |
| `__le__`   | 支持比较两个对象的大小(小于等于(**l**ess than or **e**qual))    |
| `__gt__`   | 支持比较两个对象的大小(大于(**g**reater **t**han))            |
| `__ge__`   | 支持比较两个对象的大小(大于等于(**g**reater than or **e**qual)) |
```python
class Car:
	def __init__ (self, brand, name, price):
		self.brand = brand
		self.name = name
		self.price = price
	def running(self):
		print(f"{self.brand} {self.name} 正在高速行驶...")


c1 = Car("BMW","X5",500000)
print(c1)                 #默认输出出来的是对象的内存地址(16进制)
c2 = Car ("BMW","X5",500000)
print(c2)                 #默认输出出来的是对象的内存地址(16进制)

print (c1 == c2)  #False #默认是基于对象的内存地址进行比较的

> [!warning] 不定义魔法方法时的默认行为
> 打印是内存地址、`==` 比的是内存地址、对象之间不能比大小——上面第一个例子演示的就是默认行为，不满意就得定义对应的魔法方法。

print(c1 < c2)           #默认自定义的对象之间不可以进行大小比较
```

```python
class Car:
	def __init__ (self, brand, name, price):
		self.brand = brand
		self.name = name
		self.price = price
	def running(self):
		print(f"{self.brand} {self.name} 正在高速行驶...")
	def __str__(self):
		return f"{self.brand} {self.name} {self.price}"
	def __eq__(self, other):
		return self.price == other.price and self.brand == other.brand and self.name == other.name
	def __lt__(self, other):
		return self.price < other.price

c1 = Car("BMW","X5",500000)
print(c1)          #BMW X5 500000
c2 = Car ("BMW","X5",500000)
print(c2)          #BMW X5 500000

print (c1 == c2)   #True

print(c1 < c2)     #False
```
