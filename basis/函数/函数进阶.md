## 变量作用域 #作用域
变量的作用域指的是变量的作用范围(标识这个变量在哪里可以使用，在哪儿不可以使用)
全局变量:在函数之外定义的变量，称之为全局变量，在整个文件中(包括函数内)都可以使用(通常定义在文件的顶部)
局部变量:在[[函数基础|函数]]内部定义的变量，称之为局部变量，==只能在该函数内部使用，外部无法访问(函数执行完毕后，会自动销毁其内部局部变量)==
```python
#定义函数
num = 100   #全局变量
def circle_area(r):
	pi = 3.14    #局部变量
	area=pi*r*r   #局部变量
	return area
count = 0     #全局变量
#调用函数
#使用全局变量
c_area = circle_area(10)  #全局变量
print (c_area)
```

> [!warning] 同名变量的坑
> 函数内直接给变量赋值==只会创建局部变量，不会修改同名的全局变量==（下面第一个例子，num1 依旧是 1），想改全局必须用 global。

### global关键字 #global关键字
global关键字用于明确的告诉Python解释器，在函数中要使用全局变量，使得可以在函数内部修改全局变量的值。
```python
num1 = 1 #全局变量
def fun1():
	num1 = 100 #局部变量
	print(num1)
fun1() # 100
print(num1) # 1
```

```python
num1 = 1 #全局变量
def fun1():
	global num1  #告诉python解释器,函数中使用全局变量num1
	num1 = 100 # 修改全局变量num1
	print(num1)
fun1() # 100
print(num1) # 100
```

> [!tip] global 用法口诀
> ==先声明，再使用==：global num1 必须写在函数内修改之前，顺序不能反.

> [!info] 两个例子对比
> 不加 global，函数里改的只是局部副本，外面的 num1 纹丝不动(=1)；加了 global 后函数里改的就是真正的全局变量(=100)。
注意:在基于global声明全局变量时，要先声明，再使用。
