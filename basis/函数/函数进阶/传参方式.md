传参方式指的是，在调用[[函数基础|函数]]时，传递实参的方式。 
### 1.位置参数: #位置参数
调用函数时根据函数定义时的位置来传递参数。
优点:简洁
缺点:可读性差、易出错、维护难
场景:参数少(不超过3个)，且顺序自然
```python
#定义函数
def reg_stu(name, age, gender, city):
	print(f"注册成功,姓名:{name},年龄:{age},性别:{gender},城市:{city}")
	return {"name": name, "age": age, "gender": gender, "city": city}
#调用函数
stu = reg_stu("张三",18,"男","北京")
print(stu)
```

### 2.关键字参数: #关键字参数
 调用函数时以函数定义时形参名称作为关键字，以"键=值"的形式来传递参数(==不要求顺序==)。
优点:可读性强、易维护和扩展
缺点:代码繁琐
场景:参数较多，或易混淆的场景
```python
#定义函数
def reg_stu(name, age, gender, city):
	print(f"注册成功,姓名:{name},年龄:{age},性别:{gender},城市:{city}")
	return {"name": name, "age": age, "gender": gender, "city": city}
#调用函数
stu = reg_stu(name="张三",age=18,gender="男",city="北京")
print(stu)
stu2 = reg_stu(gender="男",name="王武",city="上海",age=22)
print(stu2)
stu2 = reg_stu("赵四",28,gender="男",city="上海")
print(stu2)
```
 要求:如果位置参数与关键字参数混用，关键字参数必须在位置参数之后(关键字参数之间，没有顺序要求)

> [!warning] 混用顺序不能反
> ==关键字参数必须写在位置参数之后==，位置参数写在关键字参数后面会直接 SyntaxError。

> [!tip] 怎么选
> 参数少(不超过3个)且顺序自然用位置参数；参数多或容易混淆用关键字参数。

> [!info] 相关内容
> 本篇只管调用时怎么传；定义时给默认值见 [[默认参数]]，参数数量不确定见 [[不定长参数(可变参数)]]。
