## 介绍
类型注解是Python中的一种语法特性，用于明确标识变量、[[函数基础|函数]]参数和返回值的[[常见的数据类型|数据类型]]，从而使代码更清晰、更安全、更易维护。
```python
# 定义变量
a:int= 695
score: float = 98.5
hobby: str = "Python"
flag: bool = True
pic: None = None
names : list[str]=["A","C","E"]
phones: set[str]= {"13309091111","15209109121"}
options: dict[str, int]= {"count":0, "total": 0}
goods: tuple[str,int,int]= ("手机",5999,1)
```

1.类型注解的写法?
变量:数据类型(如 a : int)
2.常见类型的写法
int、float 、bool、[[字符串(str)|str]]、 None、[[列表(list)|list]]、 [[集合(set)|set]]、 [[元组(tuple)|tuple]]、 [[字典(dict)|dict]]
str | int

> [!info] 联合类型 str | int
> 表示这个变量可以是 str 或 int 中的任意一种。`X | Y` 是 3.10+ 的写法，更早的版本要写 `typing.Union[str, int]`。

### 类型推断 #类型推断
类型推断是指Python解释器自动推断出变量、表达式或函数返回值的数据类型的能力，而无需开发者显式声明。

注意:在对变量进行直接赋值，或者涉及到变量的运算、容器的推导等场景时，解释器会自动推导出变量的类型
Python是动态类型语言，添加的类型注解只是提示，并不是强制约束!!!

> [!warning] 注解不是强制约束
> ==类型注解只是提示，并不是强制约束==——把字符串赋给 int 注解的变量不会报错，Python 不会帮你拦，想真正检查类型要用 mypy 这类工具。

## 函数类型注解 #函数类型注解
为函数添加类型注解，其实主要就是为函数的参数和返回值添加类型注解，具体语法如下:
```python
def calc(scores: list[int]) -> float:#箭头后为返回值类型
	return sum(scores) / len(scores)
def calc_data(scores: list[int]) -> tuple[int, int, float]:
	max_v = max(scores)
	min_v = min(scores)
	avg_v = sum(scores) / len(scores)
	return max_v, min_v, avg_v
```

> [!tip] 函数类型注解的写法
> ==箭头 -> 后面写的是返回值类型==，参数的注解写在括号里(如 scores: list[int])；返回多个值时，注解写成 tuple[int, int, float]。

### 案例
电商订单计算器:
定义一个函数，用于根据传入的一批商品信息(商品名、价格、数量)、优惠(优惠券、积分抵扣)、运费信息计算订单的总金额。
具体规则如下:
优惠券需要商品金额满5000才可以使用，且优惠券金额不能超过商品总价。
积分抵扣需要商品总金额满5000才可以使用，100积分抵扣1元(且抵扣金额不能超过商品总价，积分只能整百抵扣) 

> [!info] 前向链接
> 本案例是[[函数进阶]]案例二(电商订单计算器)加上类型注解的版本。

```python
def calc_order_cost(*args: tuple[str,float,int],coupon : int = 0,score : int = 0,express : float= 0.0) -> float:
	"""
	根据传入的一批商品信息(商品名、价格、数量)、优惠(优惠券、积分抵扣)、运费信息计算订单的总金额
	:param args:商品信息(商品名、价格、数量) ---->如:("鼠标",188,2)("键盘",388,1)
	:param coupon:优惠券
	:param score:积分
	:param express:运费
	:return:订单的总金额
	"""
	#订单的总金额=商品总金额 - 优惠券 - 积分抵扣 + 运费
	#1.计算商品总金额
	total_price = [goods[1] * goods[2] for goods in args]
	total_cost = sum(total_price)
	#2.扣减优惠券
	if total_cost >= 5000 and coupon <= total_cost:
		total_cost -= coupon
	#3.扣减积分抵扣
	if total_cost >= 5000 and score//100 <= total_cost:
		total_cost -= score//100
	#4.添加运费
	total_cost += express
	
	return total_cost
```

> [!tip] *args 的注解写的是"每个参数"的类型
> `*args: tuple[str,float,int]` 注的是每个商品(单个元组)的类型，不是 args 整体；args 整体被收集后是元组，kwargs 整体被收集后是字典。
