## 介绍
函数是组织好的,可重复应用的,用来实现特定功能的代码片段.
### 函数的定义与调用
```python
# 定义函数
def 函数名(参数列表):
	函数体
	......
	return 返回值
	
def out_line():
	print('....')
#调函函数
函数名(参数)

out_line()
```
注意:函数定义时的参数列表与返回值语句是可有可无的(由需求确定)，函数必须先定义后调用执行(函数定义时，内部代码并未执行，在调用时才执行).
#### 函数的参数与返回值
在定义函数时,根据业务需要,可以指定参数与返回值
```python
# 定义函数
def circle_area(r):
	area = 3.14*r*r
	return area

#调用函数
c_area = circle_area(10)
print(c_area)

#计算长方形的面积
def rectangle_area(l,w):
	area = l * w
	return area

#调用函数
r_area = rectangle_area(20,10)
print(r_area)
```
注意:函数定义时如果有多个参数，多个参数之间使用逗号(，)分隔。
注意:return语句只有返回功能，而没有输出打印的功能，如果要输出，需要结合print()函数来实现.
