# Two Sum：从暴力到哈希的优化

> 日期：2026-10-14 ｜ 第 1 题 ｜ #LeetCode #哈希 #字典 #数组

## 问题
给定一个整数数组 nums 和一个目标值 target，找出数组中和为 target 的两个数，返回它们的下标。

## 我的解法：暴力双循环
- **思路**：两两组合，每对数试一遍是否等于 target
- **复杂度**：时间 O(n²)，空间 O(1)
- **结果**：能通过，但运行用时远超大多数用户
- **慢在哪**：内外层循环做了大量重复比较，"找配对"这件事每次都要重新扫描整个数组

## 踩过的坑
> [!warning] 提交机制与读题
> - 第一次做力扣，花时间才搞懂提交机制：**只要求写一个函数**，不用写完整程序，输入输出由平台处理
> - 读题重点看三样：输入参数、返回值、数据范围（数据范围暗示了能接受多慢的解法）

## 更优解法：哈希字典（已重做 ✅ 2026-11-11）

- **思路**：遍历数组时用[[字典(dict)|字典]]存「值 → 下标」，对每个数查 `target - nums[i]` 是否已在字典里
- **为什么快**：字典查找是 O(1)，把"找配对"从扫描整个数组变成一次查表
- **复杂度**：时间 O(n)，空间 O(n)
### 哈希版代码
```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen = {}
        for i, num in enumerate(nums):
            need = target - num
            if need in seen:
                return [seen[need], i]
            seen[num] = i
        return []
```

### 逐行解读
- `enumerate(nums)`：Python 自带函数，给每个数配上它的下标，一轮同时拿到 `i`（下标）和 `num`（数值），这道题两样都要用
- `if need in seen:`：`in` 查字典查的是键；在 = 之前见过能配对的数，就 `return [seen[need], i]`，把旧下标和当前下标一起交回去，函数结束
- **先查后存**：先查 `need`，查不到才 `seen[num] = i` 存当前数，不然会把自己和自己配成一对
- 踩坑：存的时候别写成 `seen[sum]`，`sum` 是自带的求和函数、不是当前的数，当键永远查不到（2026-11-11 自己写错过一次）

> [!warning] 键存错变量永远查不到
> `sum` 是自带的求和函数，写成 `seen[sum]` 当键永远配不上对；存值必须写 `seen[num] = i`。

> [!info] 两种解法对比
> 暴力 O(n²) 时间 / O(1) 空间 → 哈希 O(n) 时间 / O(n) 空间，==用空间换时间==。

## 一句话总结（费曼检验）
==Two Sum 用空间换时间==：字典记住见过的数，一遍遍历就能完成配对。
